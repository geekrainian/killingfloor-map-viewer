# Changelog

All notable changes to Killing Floor Map Viewer are documented here. The format follows [Conventional Commits](https://www.conventionalcommits.org/) and the version scheme is [Semantic Versioning](https://semver.org/).

## 0.1.0 (2026-08-09)

### Features

* Initial public release: desktop and browser viewer for Killing Floor `.rom` maps — world BSP, static meshes, terrain, textures and skybox, plus a Node CLI with OBJ export.
